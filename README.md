# Dev Social Tree 
A responsive personal link sharing page for developers. It allows users to display their profile and share important links in one simple interface


## features
- Responsive Designs for desktop and mobile screens.
- Personal profile section with avatar , name and short bio.
- Links to GitHub , LinkedIn and other platforms.
- Dark mode toggle.
- Smooth hover and color transactions.
